## :hammer: Fixes

- Packaging/versioning release, there are no code changes from v5.3.0. It lets the [ControllerX app](https://github.com/xaviml/controllerx-app) for Home Assistant ship as `5.3.1-1`, since its `5.3.0-1` release couldn't be installed over `5.3.0`: Home Assistant compares app versions as SemVer, where `5.3.0-1` is a pre-release and therefore older than `5.3.0`. From now on, app versions are always `X.Y.Z-N`.

# Supported controllers

ControllerX supports **72** devices out of the box. Select your device to see its default button mapping and an example configuration, or use the [configuration builder](<https://xaviml.github.io/controllerx/start/config-builder/index.md>) to generate the configuration for it.

If your device is not listed, you can still use it with a [custom mapping](<https://xaviml.github.io/controllerx/advanced/index.md>) on top of the generic controllers (`LightController`, `MediaPlayerController`, `SwitchController`, `CoverController` and `Z2MLightController`).

> [!TIP]
>
> **For tools and AI assistants**
>
> This list is also available as [JSON](<https://xaviml.github.io/controllerx/controllers/devices.json>), including the controller classes and the default mapping of every device.

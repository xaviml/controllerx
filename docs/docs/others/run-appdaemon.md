---
title: What's AppDaemon and why I need it
description: What AppDaemon is and why ControllerX is built on top of it.
---

[AppDaemon](https://appdaemon.readthedocs.io/) lets you write Home Assistant automations in Python instead of YAML. For simple automations, YAML or the automation editor are great, but when automations get more complicated, they become difficult to manage in YAML. This is where AppDaemon comes in.

This is the reason this project is built on top of AppDaemon. Now you might be convinced, but have no idea how to install and set it up. If you are using Home Assistant OS, the [installation](../start/installation.md) page explains your options: the ControllerX app, which includes its own AppDaemon, or the `AppDaemon` app from the app store with ControllerX installed in it, either through AppDaemon Store or manually.

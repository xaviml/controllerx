---
title: Update ControllerX
description: How to update ControllerX to a new version.
---

How to update ControllerX depends on how you [installed it](../start/installation.md):

- **ControllerX app:** update the app from **Settings → Apps**. The app restarts on its own.
- **AppDaemon Store:** update ControllerX from the AppDaemon Store UI (or enable auto-update). AppDaemon Store restarts the AppDaemon app on its own (see [AppDaemon Store and AppDaemon app](../start/installation.md#appdaemon-store-and-appdaemon-app)).
- **Manual installation:** replace the `controllerx` folder with the latest release and restart the AppDaemon app (see [Manual installation](../start/installation.md#manual-installation)).

With a manual installation, remember to restart AppDaemon after installing a new version of ControllerX, since AppDaemon does not reimport the modules. If AppDaemon is not restarted, it will keep running the old version.
